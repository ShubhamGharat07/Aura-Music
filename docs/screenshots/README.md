# Screenshots

This folder is ready for real Aura Music screenshots. No placeholder or
AI-generated screenshots are committed.

## Capture

1. Run the app on a phone or emulator:

   ```bash
   flutter run
   ```

2. Capture these screens in the app's dark theme, preferably at a consistent
   phone resolution (1080 x 2400 or similar):
   - `home.png` — Home feed
   - `search.png` — Search with results
   - `player.png` — Now Playing / expanded player
   - `library.png` — Library
   - `downloads.png` — Downloads
   - `settings.png` — Settings

3. Save the PNG files in this folder using the names above.

4. Update the **Screenshots** section in the root
   [README.md](../../README.md) with a table like this:

   ```markdown
   | Home | Player | Library |
   |:---:|:---:|:---:|
   | ![Home](docs/screenshots/home.png) | ![Player](docs/screenshots/player.png) | ![Library](docs/screenshots/library.png) |
   ```

Use real app UI only. Do not include personal playlists, account details,
notifications, or other private information in a screenshot.
